# Аудит безопасности Tabora, второй круг (после исправлений 58baa9f..5af4608)

Шесть независимых проверок тех же участков с задачей обойти исправления первого круга, найти внесённые ими
ошибки и пропущенное. Критических обходов нет; ниже открытые находки. Тесты агентов:
`scratchpad/audit2-{wallet,vault,shell,updates}/` текущей сессии.

## High

1. **Сейф: повреждённый файл заменяется новым ключом на втором запуске.** `vault/Vault.sys.mjs:357-361,390,618-622`.
   После переноса в `.corrupt-*` следующий запуск видит «нет файла», `ensureForPasswords` создаёт новый K, `_save`
   затирает `.bak`. То же для кодов: `vault/Otp.sys.mjs:410-418,432-434,529-540`.
   Исправление: при отсутствии файла и наличии `.bak`/`.corrupt-*`/`logins.db`/`tabora-otp.json` оставаться в
   состоянии corrupt; не перезаписывать `.bak` ключом с другим `check`.
2. **Сейф: `lock()` во время операций с ключом.** `Vault.sys.mjs:1066-1072` (вне `_exclusive`), `930,948,989,1262-1270`.
   Блокировка во время Argon2 в `changePassword`/`setPassword` заворачивает нулевой ключ; в `rotateKey` снимает
   блокировку или шифрует нулевым подключом. Исправление: `lock()` через `_exclusive`, обработчикам копии ключей.
3. **Кошелёк: «известный» обмен скрывает получателя.** `wallet/WalletSigner.sys.mjs:244-252`, `provider.js:1039-1042`.
   Uniswap V2/V3, Kyber с чужим `to`/`recipient` показываются как обычный обмен без `danger`.
   Исправление: получатель обязан быть своим адресом, иначе опасно; нулевой `amountOutMin` помечать.
4. **Агент: разрешение шире действия.** `agent.js:847` (ключ `mail` общий для `find_code` и `inbox`), `:774` (история),
   `:608,1013-1016,502` (данные прошлых ходов уходят на тот же origin через `open_url`/`fill_form` без вопроса).
   Исправление: ключ разрешения с действием и аргументом; после чтения недоверенного содержимого любое действие с
   данными (URL с новым query/путём, значения полей из результатов инструментов) требует подтверждения.
5. **macOS: приложение не подписано.** Нет Developer ID, hardened runtime, нотаризации; ресурсы не запечатаны,
   возможна подмена `omni.ja`/`policies.json` и внедрение кода. Нужен аккаунт Apple Developer (владелец).
6. **Домен tabora.app зашит в сборку и не куплен** (`app.update.url.manual`, `tabora.url.*`, `tabora.account.domain`,
   application.ini). Купить до любого распространения (владелец).
7. **Сервер: резервных копий нет**, восстановление из снапшота оставит сервер без сети и входа (cloud-init отключён,
   netplan по MAC, пароль root заблокирован).

## Medium

- Обновления: срок действия манифеста не проверяется, старый подписанный манифест принимается
  (`update/TaboraUpdate.sys.mjs:172-175,245,363-365,409-417`); `release.py refresh`/`manifest` переподписывают
  непроверенное содержимое `updates/` (`tools/release.py:623-633,568-582`); sha512 скачанного файла не сверяется;
  неподписанные атрибуты update.xml; `%CHANNEL%` зависит от `app.partner.*`.
- Агент: кнопка `ask_user` считается сообщением пользователя (`agent.js:1168,375`); `nav:<origin>` одобряется раз
  на ход, редиректы не сверяются (`:609,756`); обход `list_tabs` через `switch_tab` и `bookmarks add`
  (`:625-635,797-803`); клики и ввод на доверенном сайте без вопроса (SPA); карточка обрезает адрес до 160 символов.
- Сейф/аккаунт: счётчик попыток сбрасывается входом в чужой аккаунт (`account/Account.sys.mjs:594,478-480`) и может
  запереть владельца при сдвиге часов (`Vault.sys.mjs:262-282`); записи без `flush`; HMAC метаданных кодов снимается
  удалением `macs` (`Otp.sys.mjs:469,489-491`); `setPassword` без проверки владельца через вход
  (`Account.sys.mjs:484-491`); ключ проверки на сервере равен ключу подписи сброса (`:66-68,205-209`).
- Кошелёк: обход пересчёта адресов (`WalletStore.sys.mjs:722-762,200-210`: пустой `good`, подстановка `check` как
  seed, нет AAD); обход защиты от отравления (`send.js:146-154`, `WalletStore.sys.mjs:1481-1483,1722-1739`: входящие
  контрагенты «знакомы», пыль < 1e-8 даёт NaN); откат к v2-`check` (`:508-518,704-710`).
- Сборка: локальный dmg не релизный (crashreporter в Mozilla, devtools.chrome, remote debugging, грязное дерево);
  Safe Browsing без ключа шлёт данные о загрузках в Google; каналы Mozilla/Google (system addons, GMP, ASRouter,
  captive portal, region, UITour permissions).
- Сервер: ключ API tabora-server может сменить пароль любому пользователю (проверить, может ли администратору);
  fail2ban считает 401 без авторизации и `recidive` банит порт 22 (можно забанить владельца); нет мониторинга;
  данные не зашифрованы (`encryptionAtRest: Disabled`).
- GitHub: 33 коммита не отправлены (действует старый workflow); ключи подписи без пароля, запасной рядом.

## Low

Кошелёк: порог пароля на каждую операцию отдельно, multicall снимает `danger`, `removeLoginKey` до `save`
(`WalletStore.sys.mjs:952`), неизвестные инструкции System/Token в Solana, порт в SIWE, `wLookalike`.
Агент: ссылки в ответе модели, `close_tabs` по 3, `el.click()` доверенный, скрытый текст читается, `target_origin`
от контент-процесса. Оболочка: `moveTabToSpace` с системным принципалом (`tabora.js:755-757`), актор TaboraVault без
`remoteTypes`, `cookieBannerHandled` без ограничения частоты. Сейф: `resumeRekey` без обработчика паролей
(`Vault.sys.mjs:1291`), все мигрированные записи кодов `sub: true`. Сервер: `AllowTcpForwarding no` ломает доступ к
панели по README, нет `postmaster@`, `setup-tunnel.sh:54` без `type=CNAME`, `/var/www/tabora.app` принадлежит
www-data, карта привилегированных логинов 644. Сборка: Team ID Mozilla в Info.plist, `app.update.interval` дважды.
CI: `sign` берёт скрипты из коммита сборки, тег релиза на HEAD main, verify.sh вендоров не вызывается в CI.

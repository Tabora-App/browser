# Tabora для iPhone

Только iPhone (не iPad). На iPhone браузеру разрешён один движок — системный WebKit, тот же, что у
Safari, поэтому наш движок Gecko здесь не используется. Основа — Firefox для iOS
(mozilla-mobile/firefox-ios, лицензия MPL 2.0): он целиком работает на WebKit и даёт готовую оболочку
браузера. Из него убраны службы Mozilla и поставлено всё своё: имя, знак, цвета, ярлыки.

## Как собрать

Нужны Xcode 27.1 или новее (проверено на 27.2), Node.js и около 12 ГБ на диске.

```sh
python3 tools/ios/build.py fetch      # исходники Firefox для iOS — коммит из browser.json, раздел ios
python3 tools/ios/build.py prepare    # генератор настроек (закреплённый сценарий), скрипты страниц
python3 tools/ios/build.py import     # наложить наши правки из каталога ios/
python3 tools/ios/build.py build      # приложение для симулятора iPhone
python3 tools/ios/build.py run        # поставить в симулятор и запустить
python3 tools/ios/build.py shot a.png # снимок экрана симулятора
```

Для симулятора подпись не отключается (Xcode подписывает сам, профили не нужны): только с ней у
приложения есть общее хранилище группы — без него оно запускается, но не сохраняет вкладки.

Исходники Firefox для iOS в репозитории не хранятся: они скачиваются в `.build/ios/firefox-ios`
(один закреплённый коммит без истории). Всё наше лежит в каталоге `ios/` в корне репозитория (не в `src/`: его содержимое сборка
браузера накладывает на движок Firefox) и повторяет пути исходников:
`файл.patch` — правка существующего файла, остальное — файлы целиком. Правки, сделанные прямо в
исходниках, превращает в патчи `tools/ios/build.py export`; `reset` возвращает чистый Firefox.

Две вещи `import` делает сам, без патчей, потому что файлы огромные и меняются в каждом выпуске:

- файл проекта Xcode: только iPhone, без запасных значков Firefox, без лишних расширений;
- название в надписях: «Firefox» → «Tabora» в текстах переводов на всех языках (только в тексте
  надписи, не в ключе) и в английских надписях в `Strings.swift`.

Сборка на GitHub — workflow **iOS** (`.github/workflows/ios.yml`, запуск вручную): собирает приложение
для симулятора с чистого листа.

Картинки (значок, заставка, знак вместо логотипов и лисы Firefox, надпись в шапке) рисует
`tools/ios/assets.py`; готовые файлы лежат в `ios/`.

## Что изменено

- Имя Tabora, пакет `app.tabora.browser`, версия как у остальных сборок. Сайтам называется версия
  Firefox для iOS, на которой основано приложение (токен `FxiOS/160.0`), а не номер выпуска Tabora.
- Значок, заставка и все картинки с логотипом и лисой Firefox заменены знаком Tabora.
- Цвета — палитра Tabora, та же, что в приложении Android (оформление Nova).
- Ярлыки на домашней странице: первой идёт почта Tabora (`app.tabora.app`).
- Языки — все, что есть в Firefox для iOS, включая русский, английский, украинский и испанский.
- Блокировка рекламы включена с первого запуска (в Firefox её включают вручную), а защита от
  отслеживания — строгая: блокируются и сами счётчики, а не только их cookies. Список блокировки
  рекламы загружается при запуске и обновляется вместе с настройками. Выключается в
  «Настройки → Просмотр сайтов».

Выключено для всех и не включается из настроек:

- телеметрия (Glean), отчёты о сбоях (Sentry), эксперименты и опросы Mozilla;
- приветствие Firefox: условия использования Mozilla, согласие на отправку данных, вход в аккаунт;
- аккаунт Mozilla и синхронизация: вход в настройках и меню, вкладки с других устройств,
  «Отправить на устройство», уведомления через сервер Mozilla;
- спонсорские ярлыки, лента историй, подсказки Firefox Suggest, ярлык Google с партнёрским кодом;
- партнёрские коды Firefox в поисковых запросах;
- пересказ страниц на серверах Mozilla, Relay, VPN, «Сообщить о проблеме с сайтом»;
- сведения об установке для рекламной атрибуции (SKAdNetwork);
- разделы настроек с отправкой данных, отзывами, справкой Mozilla, уведомлениями Mozilla и оценкой
  Firefox в App Store; плашка «сделать браузером по умолчанию» в меню (до разрешения Apple).

Остаётся обращение к серверу настроек Mozilla (Remote Settings): оттуда приложение берёт список
поисковиков, списки блокировщика рекламы и модели перевода страниц. Личных данных туда не уходит.

В сборке для разработки нужный экран можно открыть при запуске — так проверки снимают экраны без
нажатий: `SIMCTL_CHILD_TABORA_OPEN="tabora://deep-link?url=/settings/general" xcrun simctl launch
"iPhone 17" app.tabora.browser`. Кроме ссылки понимаются слова `menu` (главное меню) и `tabs`
(лоток вкладок); язык приложения задаётся параметрами запуска `-AppleLanguages "(en)"`.

## Чего пока нет

- Разделов аккаунта Tabora в приложении: почта открывается ярлыком в веб-версии.
- Кошелька: Apple принимает кошельки только от разработчиков-организаций.
- Виджетов, стикеров и подстановки паролей в другие приложения: в Firefox они нарисованы с его
  логотипами или работают через аккаунт Mozilla, в приложение пока не встраиваются.
- Ссылок «Подробнее» на свою справку: они ведут на справку Mozilla.
- Выбора «браузер по умолчанию»: для него нужно отдельное разрешение Apple
  (`com.apple.developer.web-browser`), запрашивается у Apple под аккаунтом разработчика.

## Что нужно для телефона и App Store

Сборка для телефона (`build.py build --device`) и выкладка требуют действий в аккаунте разработчика
Apple, которые делает владелец аккаунта:

1. Идентификаторы приложения: `app.tabora.browser`, `app.tabora.browser.ShareTo`,
   `app.tabora.browser.ActionExtension`; группа приложений `group.app.tabora.browser`.
2. Профили подписи для них (сертификат Apple Distribution на этом компьютере есть).
3. Запись приложения в App Store Connect, описание, снимки, адрес политики конфиденциальности.
4. Заявка Apple на право быть браузером по умолчанию.

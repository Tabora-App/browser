# Архитектура

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Движок | Firefox (Gecko), свой инструмент сборки поверх mach | Интерфейс на HTML/CSS/JS, сборка 1,5-2 часа на ноутбуке, macOS собирается на Linux, uBlock Origin работает, Firefox Sync открыт |
| Интерфейс | Полностью свой, по макетам Claude Design | Боковая панель с пространствами, спящие вкладки, панель агента |
| Сборка релизов | Blacksmith, Linux-раннеры, кросс-компиляция macOS | Бесплатных минут хватает на все платформы |
| Мобильные | Android на GeckoView/Fenix, iOS на WebKit | Требования магазинов; агент работает только внутри вкладок браузера |

## Слои

1. **Движок**: Firefox без изменений, обновляется раз в 4 недели сменой версии в `browser.json`.
2. **Оболочка** (`src/browser/`): боковая панель, пространства, спящие вкладки, стартовая страница, настройки. Привилегированный JS, CSS, XHTML.
3. **Агент**: модуль оболочки с доступом к страницам через JSWindowActor. Планирует шаги, заполняет формы, создаёт алиасы, читает коды из встроенной почты, ждёт подтверждения пользователя перед отправкой форм.
4. **Почта и алиасы**: отдельный сервис на своём домене (JMAP/IMAP), клиент внутри браузера как встроенная страница.
5. **Синхронизация**: самостоятельно размещённый сервер Firefox Sync, шифрование на устройстве.
6. **Блокировка**: встроенная защита от трекинга Firefox плюс полноценный uBlock Origin.

## Фичи, которых не дал Chrome (приоритет на старт)

- Поиск по смыслу в истории, индекс локально.
- Автоархив вкладок, которые не открывали несколько дней.
- Автоотказ от cookie-баннеров.
- Спящие вкладки с освобождением памяти, видимый счётчик RAM.
- Алиасы почты: отписка от рассылки отключением алиаса.

Кошелёк для семи сетей на одной фразе

Адреса Ethereum, Base, Arbitrum, Polygon, Bitcoin, Solana и TRON выводятся из одной фразы восстановления. Фраза зашифрована паролем кошелька и лежит на вашем компьютере.

Сайты видят кошелёк сами
Tabora поддерживает EIP-6963 и EIP-1193 для Ethereum, Wallet Standard для Solana и совместим с TronLink. На сайтах вроде Uniswap достаточно нажать «Подключить».
Перед подписью видно, что произойдёт
Кошелёк сам разбирает транзакцию: сколько уйдёт, кому придут токены, какой лимит просит контракт. Опасные подписи EIP-712 и бесконечные разрешения помечаются.
Адреса-двойники не попадают в историю
Входящая «пыль» с адресов, похожих на ваши, скрывается, чтобы вы не скопировали чужой адрес по ошибке.
Имена .eth и ссылки ipfs://
Открываются прямо из строки адреса через публичные шлюзы. Шлюзы можно сменить в настройках.

Почта на tabora.app и отдельный адрес для каждого сайта

У вас будет адрес вида имя@tabora.app. При регистрации на сайте браузер предложит алиас, например booking-k3f9@tabora.app. Письма приходят в один ящик, и по алиасу видно, какой сайт их прислал.

Отписка одним переключателем
Сайт начал слать рекламу или адрес утёк — выключите алиас, и письма на него перестанут приходить. Основной адрес сайт не знает.
Коды из писем без похода в почту
Агент находит код подтверждения в свежем письме и вставляет его в форму.
Письма на диске зашифрованы
Сохранённая почта шифруется ключом сейфа и закрывается вместе с ним.

Адреса на tabora.app начнём выдавать, когда откроем регистрацию. В версии 0.1 раздел почты показывает пример ящика.

Пароли и коды входа под одним мастер-паролем

Сейф хранит пароли сайтов и коды двухфакторного входа. Они зашифрованы ключом, который открывается мастер-паролем или связкой ключей macOS. Мастер-пароль никуда не отправляется.

Коды без телефона
Добавьте код по QR со страницы или с экрана, перенесите из Google Authenticator, Aegis или 2FAS. Браузер подскажет код в поле входа только на том сайте, к которому код привязан.
Буфер обмена чистится сам
Скопированный код исчезает из буфера через 30 секунд и не остаётся в его истории.
Подбор пароля стоит дорого
Мастер-пароль превращается в ключ через Argon2id с 64 МБ памяти на каждую попытку.
Ключ восстановления
Если забудете мастер-пароль, сейф откроется ключом, который вы сохраните при создании.

Агент, который спрашивает, прежде чем отправить

Поручите агенту рутину: зарегистрироваться на сайте, найти письмо, заполнить форму. Он работает во вкладках браузера на вашем ключе OpenAI, а ключ хранится в сейфе.

Подтверждение перед важным
Отправку форм и переходы по ссылкам из текста страницы агент показывает карточкой с настоящим доменом сайта. Без вашего согласия ничего не уйдёт.
Текст страницы не командует агентом
После чтения страницы или письма каждое следующее действие требует подтверждения. Так чужой текст не сможет увести ваши данные.

Можно включить усыпление вкладок после простоя, чтобы освободить память. По умолчанию выключено; вкладки со звуком и звонками не засыпают.
Защита от трекеров
Встроенная защита Firefox и расширения из каталога Firefox, включая uBlock Origin.
Одна строка для всего ⌘K
Ищет по вкладкам и истории, открывает разделы и принимает поручения агенту.

Код открыт, проверки опубликованы

Исходный код Tabora лежит на GitHub под лицензией MPL 2.0, как и код Firefox. Отчёты об аудитах безопасности и описание устройства сейфа и кошелька лежат там же.

Подписанные обновления
Пакет обновления подписан ключом Tabora. Сведения о версиях подписаны отдельным ключом Ed25519 и имеют срок годности. Установщик для Mac заверен Apple.
Проверяемые библиотеки
Криптографические библиотеки кошелька и сейфа собираются из закреплённых версий. Совпадение файла в репозитории со сборкой проверяет один скрипт.
Движок следует за Firefox
Tabora обновляет движок вслед за выпусками Firefox, вместе с исправлениями безопасности.

Как проверить файл

  1. Посчитайте контрольную сумму и сравните с той, что на этой странице.

    shasum -a 256 ~/Downloads/Tabora-0.1.0-mac-aarch64.dmg

  2. Проверьте, что установщик заверен Apple.

    spctl -a -vv -t install ~/Downloads/Tabora-0.1.0-mac-aarch64.dmg

    В ответе должно быть Notarized Developer ID и идентификатор команды 7YQU9YBJQ8.
